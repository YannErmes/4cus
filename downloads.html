Before you install

🌐

Web

Nothing to install, nothing to sign. The fastest way in, and it updates itself. The web zip is only for running it offline from a local folder.

🤖

Android

Download the APK, allow "install from unknown sources" for your browser, and open it. Android may ask you to uninstall an older build first if a version with the same number is installed.

🪟

Windows

Unzip the whole folder — the executable needs the DLLs next to it — then run 4cus.exe. Nothing is installed system-wide.

🍎

iOS

Published unsigned. iOS refuses to install an unsigned app on a real device; it needs an Apple Developer signature, which costs $99/year. Use the web app on your phone today.
