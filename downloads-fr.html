Avant d'installer

🌐

Web

Rien à installer, rien à signer. Le moyen le plus rapide d'entrer, et les mises à jour sont automatiques. Le zip web sert uniquement à faire tourner l'application hors ligne depuis un dossier local.

🤖

Android

Téléchargez l'APK, autorisez « installer depuis une source inconnue » pour votre navigateur, puis ouvrez-le. Android peut demander de désinstaller une version plus ancienne si une version portant le même numéro est installée.

🪟

Windows

Décompressez le dossier entier — l'exécutable a besoin des DLL à côté de lui — puis lancez 4cus.exe. Rien n'est installé au niveau système.

🍎

iOS

Publié non signé. iOS refuse d'installer une application non signée sur un vrai appareil ; il faut une signature développeur Apple, à 99 $/an. Utilisez la version web sur votre téléphone aujourd'hui.
