Your tools make you pick a side

Almost every planner answers half the question. The result is three tabs open and still no answer to the only one that matters: did I actually do what I said I would on Tuesday?

📅

A calendar knows when

It does not know how long something takes, whether you actually did it, or that "gym" is a 45-minute routine and not a 24-hour event.

✅

A to-do list knows what

Everything sits in one long column. "Wednesday" is a due date, not a place you can see your whole week at once.

⏱️

A time tracker is always late

It tells you, weeks later, where the hours went. It never helps you decide where they should go tomorrow.

How 4cus works

Three steps, and the grid fills itself in as you commit.

Add a routine

Create the things you actually repeat — gym 45 min, deep work 2 h, call mom. They live in a pool. You are not committing to a day yet.

Place it on days

Tap a day and pick a status. idle means "not this day", so the grid is your plan. Statuses are yours: none, in progress, done, cancelled.

Run it, then compare

Start a timer inside a cell and the day fills with real time. The analytics show planned vs done vs left, per task and per week.

Questions, answered

Is 4cus free?
Yes. 4cus is free to use on every platform. An optional VIP key unlocks Google Calendar sync and a few extras — the core tracker never sits behind a paywall.
Do I need an account or a password?
No password. You type an email address and your workspace is created instantly. Use the same address on every device and you get the same data everywhere — so remember it exactly.
Where is my data stored?
In a Supabase project, with row level security so a workspace can only ever read its own rows. A local copy is kept on the device, which is also what makes offline editing work.
Does it work offline?
Yes. Changes are queued locally and pushed when the connection returns. You will see the sync status in the app when something is pending.
Can I install it on my iPhone?
The iOS build is published unsigned, so iOS will not install it on a real device without an Apple Developer signature. In practice, use the web app or the Android build on a phone today.
Is there an app store version?
Not yet. The Android APK is the current install path; a store release is on the list of things to do.
Can I import from Notion, Todoist or a spreadsheet?
Not yet. It is a clearly wanted feature — for now, the fastest route is to recreate your routines as tasks with durations; the grid does the rest.
What is the "idle" status for?
It means "not scheduled this day". That is what lets a single recurring task live in one row while only appearing on the days you actually committed to — the grid stays honest instead of pretending a task is planned every day.
